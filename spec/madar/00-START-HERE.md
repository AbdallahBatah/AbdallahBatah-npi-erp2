# ٠٠ — ابدأ من هنا
**المشروع:** مَدار — الطبقة الحوارية لـ NPI ERP | **إصدار الحزمة:** 3.0 | **التاريخ:** 21 سبتمبر 2026 | **يحل محل:** 2.0 (طُويت) | **المسار:** مشروع قائم (حزمة فرق على مستودع `npi-erp`)

## ١. ما هذه الحزمة؟
اثنا عشر ملفاً تصف طبقة جديدة تُضاف إلى NPI ERP القائم دون المساس بنواته: الموظف يكتب في محادثة ويرفق صورة العقد أو ملف PDF، فيقرأ وكيله المستند ويعرض «هذا ما سأُدخله»، وبعد اعتماده يُدخل البيانات عبر مسار NPI نفسه (صلاحياته، مصفوفة اعتماداته، محرك تدفقاته، سجل تدقيقه). أنت تقرأ الملفات العربية (٠٠، ٠١، ٠٩، ١٠) وتلصق الأوامر؛ وClaude Code يقرأ الباقي وينفّذ داخل مستودع NPI.

## ٢. ماذا سيُبنى (في أربعة أسطر)
1. **تطبيق «مَدار» داخل مستودع NPI** (`apps/copilot`) يعمل حاويةً بجانب `api` و`web`، يدخله الموظف بحساب NPI نفسه.
2. **الإدخال بالمحادثة لخمسة تدفقات:** عميل وعقد بمراحله من مستند، طلب شراء، أمر شراء، استلام بضاعة، فاتورة مورد — كل واحد ببطاقة معاينة واعتماد ثم تنفيذ عبر واجهة NPI البرمجية بصفة المستخدم؛ **لا كتابة مباشرة في قاعدة البيانات أبداً، ولا تجاوز لمصفوفة الاعتمادات ولو للمالك.**
3. **يتشكل حسب النشاط:** محادثة تأسيس تختار ملف النشاط من كتالوج ستة (EPC، تشغيل وصيانة، مشغّل PPA/تأجير، مقاولات عامة، تجارة معدات، استشارات هندسية) فتضبط إعدادات NPI عبر واجهته الإدارية (الأقسام، صلاحيات الأدوار، قواعد الاعتماد، الأصناف، الترقيم) وتضبط ما يظهر في المحادثة (الوحدات، المصطلحات، المستندات المقبولة).
4. **الحوكمة:** وكيل لكل منصب يرث دور المستخدم وقسمه من NPI ويسلّم خلفه دليل استلام؛ ذاكرة مؤسسية؛ إخفاء للنص قبل أي نموذج خارجي؛ سجل تدقيق للنماذج؛ عدّاد كلفة؛ لوحة قياس لستة افتراضات.

## ٤. خطوات الاستخدام بالترتيب
1. ضع ملفات هذه الحزمة في `C:\dev\npi-erp\spec\madar\`.
2. أضف إلى `.env` المحلي سطر `ANTHROPIC_API_KEY=المفتاح` (وإلى `deploy/.env` على الخادم عند المرحلة ٥). لا يُرفع أبداً.
3. افتح Claude Code في `C:\dev\npi-erp` والصق **أمر الفحص المسبق** من `08` (A).
4. الصق **أمر المرحلة صفر** من `08` (B): تدقيق تحقق + الإصلاحان العاجلان (الترقيم في رأس السنة، تجاوز الاعتماد). ستصلك نتيجة عربية؛ اكتب «موافق».
5. الصق **أمر التشغيل الأول** من `08` (C). خمس مراحل بعد الصفر؛ عند نهاية كل مرحلة تنفّذ سيناريو `09`.
6. جلسة جديدة؟ **أمر الاستئناف** من `08` (D).
7. التشغيل المحلي للتجربة: `npm run copilot:dev` (يشغّل api + copilot معاً) ثم `http://localhost:3100`.
8. النشر على خادم العرض (المرحلة ٥): `deploy\pack.ps1` ثم `sh deploy/deploy.sh` كما تفعل اليوم؛ الطبقة تُنشر معه على `https://<النطاق>/copilot`.

## ٥. كيف توافق وتبلّغ
«موافق» في Claude Code للبوابات؛ الصف الفاشل من `09` إلى محادثة المهندس؛ تغيير الميزات عبر المهندس؛ إصلاح خطأ صغير يجوز مباشرة من Claude Code.
